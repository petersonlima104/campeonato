# 🏆 Sistema Profissional de Gerenciamento de Campeonato

Plataforma web completa para **organização, gestão e divulgação de campeonatos esportivos**, com classificação automática, controle de jogos, rankings individuais e painel administrativo seguro.

Desenvolvido para **ligas, campeonatos amadores, escolinhas, torneios regionais e organizadores profissionais**, o sistema reduz erros humanos, automatiza cálculos e oferece uma experiência moderna para administradores e público.

## 🧩 Funcionalidades do Sistema

### 📊 Classificação de Times
- Pontos (P)
- Partidas Jogadas (PJ)
- Vitórias (VIT)
- Empates (E)
- Derrotas (DER)
- Gols Marcados (GM)
- Gols Sofridos (GC)
- Saldo de Gols (SG)

📌 **Critérios de desempate automáticos:**
1. Pontos  
2. Vitórias  
3. Saldo de gols  
4. Gols marcados  

---

### ⚽ Gestão de Jogos
- Cadastro por modal (interface amigável)
- Seleção de mandante e visitante a partir dos times cadastrados
- Atualização automática da classificação ao salvar o jogo
- Edição e exclusão controladas pelo administrador

---

### 🥅 Artilheiros & 🎯 Assistências
- Ranking automático por desempenho
- Associação correta jogador → time
- Busca dinâmica por:
  - Nome do jogador
  - Nome do time
- Interface rápida para edição administrativa

---

### 🔍 Pesquisa Inteligente
- Filtro em tempo real
- Não exige botão
- Ideal para campeonatos com muitos jogadores
- Facilita uso do público e do administrador
